B. Random Generators in R

Sebagai salah satu bahasa pemrograman yang hadir karena kebutuhan akan komputasi statistik, R telah menyiapkan banyak fungsi untuk membangkitkan data berdasarkan sebaran. Fungsi peluang suatu sebaran dalam R ditandai dengan prefix sebagai berikut:

Prefix Makna Definisi Sederhana
r- random Membangkitkan data acak dari suatu distribusi.
d- density Menghitung nilai kepadatan atau peluang pada suatu nilai x.
p- probability Menghitung peluang kumulatif sampai nilai x.
q- quantile Mencari nilai x berdasarkan peluang kumulatif tertentu.

1. Inverse Transform Method

Inverse Transform Method adalah teknik membangkitkan bilangan acak dari suatu distribusi tertentu dengan memanfaatkan bilangan acak Uniform U(0,1).

Ide dasarnya:

\[U \sim U(0,1)\]

kemudian nilai U tersebut dimasukkan ke invers fungsi distribusi kumulatif (CDF):

\[X = F^{-1}(U)\]

Hasil X akan mengikuti distribusi yang diinginkan.

Algoritma Inverse Transform Method adalah sebagai berikut:

  1. Tentukan distribusi yang ingin dibangkitkan dan CDF-nya,

    \[F(x) = P(X \leq x)\]

  2. Bangkitkan bilangan acak

    \[U \sim U(0,1)\]

  3. Bentuk persamaan:

    \[U = F(X)\]

  4. Cari invers CDF sehingga diperoleh:

    \[X = F^{-1}(U)\]

  5. Nilai X yang diperoleh merupakan bilangan acak dari distribusi yang diinginkan.

Contoh

Bangkitkan bilangan acak yang berdistribusi \(exponential(2)\) dengan Inverse Transform Method, yang amatannya berjumlah \(10\).

1. Tentukan CDF

CDF dari distribusi Eksponensial adalah:

\[F(x) = 1-e^{-\lambda x}\]

CDF dari \(\text{Exponential}(2):\)

\[F(x) = 1-e^{-2x}\]

2. Ganti \(F(x)\) dengan \(U\)

Karena:

\[U = F(X)\]

maka:

\[U = 1 - e^{-2X}\]

3. Cari \(X\)

Mulai dari:

\[U = 1 - e^{-2X}\]

Pindahkan:

\[e^{-2X} = 1-U\]

Gunakan algoritma:

\[-2X = \ln(1-U)\]

Sehingga:

\[X = -\frac{1}{2}\ln(1-U)\]

Secara umum:

\[\boxed{ X = -\frac{1}{\lambda}\ln(1-U) }\]

Inilah invers CDF dari distribusi Eksponensial.

Contoh dengan angka:

Misalnya dari Uniform diperoleh:

\[U = 0.6\]

dan:

\[\lambda = 2\]

Maka:

\[X = -\frac{1}{2}\ln(1-0.6)\]

\[X = -\frac{1}{2}\ln(0.4)\]

karena:

\[\ln(0.4) \approx -0.9163\]

maka:

\[X = -\frac{1}{2}(-0.9163)\]

\[\boxed{X \approx 0.458}\]

Artinya bilangan Uniform:

\[U = 0.6\]

setelah melalui inverse transform berubah menjadi:

\[X \approx 0.458\]

yang merupakan bilangan acak dari distribusi Eksponensial dengan \(\lambda = 2\).

Implementasi di R:

Di soal disebutkan bahwa kita akan membangkitkan 10 bilangan acak, maka:

2. Acceptance-Rejection Method

Acceptance-Rejection Method adalah teknik pembangkitan bilangan acak dengan cara membangkitkan calon nilai dari suatu distribusi yang lebih mudah dibangkitkan, kemudian calon tersebut diperiksa apakah diterima atau ditolak.

Algoritma Acceptance-Rejection Method adalah sebagai berikut:

  1. Tentukan distribusi target dengan PDF:

\[f(x)\]

  1. Pilih distribusi proposal \(Y\) yang mudah dibangkitkan dengan PDF:

\[g(y)\]

  1. Tentukan konstanta:

\[c = \max_y \frac{f(y)}{g(y)}\]

  1. Bangkitkan kandidat:

\[Y \sim g(y)\]

  1. Bangkitkan:

\[U \sim Uniform(0,1)\]

  1. Hitung:

\[\frac{f(Y)}{c\,g(Y)}\]

  1. Jika:

\[U \leq \frac{f(Y)}{c\,g(Y)}\]

maka terima:

\[X = Y\]

  1. Jika tidak memenuhi syarat, tolak \(Y\), kemudian ulangi langkah 4-7 sampai jumlah bilangan acak yang diinginkan terpenuhi.

Contoh:

Bangkitkan peubah acak \(X \sim Beta(2,2)\) yang memiliki fungsi PDF:

\[f(x) = 6x(1-x), 0<x<1\]

dengan menggunakan Acceptance-Rejection Method sebanyak 100 amatan. Kemudian gambarkan histrogramnya!

Penyelesaian:

1. Tentukan distribusi target

Distribusi target adalah:

\[X \sim Beta(2,2)\]

dengan PDF:

\[f(x) = 6x(1-x), \qquad 0 < x < 1\]

2. Tentukan distribusi proposal

Pilih:

\[Y \sim U(0,1)\]

karena memiliki domain yang sama dengan distribusi target, yaitu antara 0 dan 1.

PDF dari \(Y\) adalah:

\[g(y) = 1, \qquad 0 \leq y \leq 1\]

3. Hitung Nilai \(c\)

Nilai \(c\) dicari dari:

\[c = \max_y \frac{f(y)}{g(y)}\]

Karena:

\[f(y) = 6y(1-y)\]

dan:

\[g(y) = 1\]

Maka misalkan saja \(h(y) = \frac{f(y)}{g(y)}\), sehingga

\[h(y) = \frac{6y(1-y)}{1} = 6y(1-y)\]

Untuk mencari nilai maksimum dari \(h(y)\) maka kita harus menyelesaikan persamaan:

\[\frac{d h(y)}{dy}=0\]

Dengan menggunakan aturan perkalian pada turunan maka didapatkan:

\[\begin{aligned} 6(1-y)-6y &= 0 \\ 6-6y-6y &= 0 \\ 6-12y &= 0 \\ y &=\frac{1}{2} \\ \end{aligned}\]

Subtitusi \(y=\frac{1}{2}\) ke \(h(y)\) sehingga didapatkan:

\[h(\frac{1}{2}) = 6(\frac{1}{2})(1-\frac{1}{2})=\frac{3}{2}\]

sehingga nilai \(c=1.5\)

4. Tentukan aturan penerimaan

Syarat Acceptance-Rejection adalah:

\[u \leq \frac{f(y)}{c\,g(y)}\]

Substitusikan:

\[f(y) = 6y(1-y)\]

\[g(y) = 1\]

dan:

\[c = 1.5\]

sehingga:

\[u \leq \frac{6y(1-y)}{1.5(1)}\]

atau:

\[\boxed{u \leq 4y(1-y)}\]

Jadi:

  • Jika \[u \leq 4y(1-y)\]

    maka \(Y\) diterima dan dijadikan \(X\).

  • Jika tidak, \(Y\) ditolak dan proses diulang.

Proses dilakukan sampai diperoleh 100 nilai \(X\) yang diterima.

5. Implementasi di R

# Tentukan banyaknya amatan
n <- 100

# Tentukan fungsi h(y) dan cari nilai c
h <- function(y) {
  6 * y * (1 - y)
}

hasil_opt <- optimize(
  f = h,
  interval = c(0, 1),
  maximum = TRUE
)
hasil_opt
$maximum
[1] 0.5

$objective
[1] 1.5
# Nilai y saat fungsi mencapai maksimum
cmax <- hasil_opt$maximum

# Nilai maksimum fungsi = konstanta c
copt <- hasil_opt$objective

# Tampilkan hasil
cmax
[1] 0.5
copt
[1] 1.5
# Proses Acceptance-Rejection
set.seed(123)

x <- numeric(0)

while (length(x) < n) {
  
  # Bangkitkan kandidat Y ~ Uniform(0,1)
  y <- runif(1, min = 0, max = 1)
  
  # Bangkitkan U ~ Uniform(0,1)
  u <- runif(1, min = 0, max = 1)
  
  # PDF target
  f_y <- 6 * y * (1 - y)
  
  # PDF proposal
  g_y <- 1
  
  # Aturan Acceptance-Rejection
  if (u <= f_y / (copt * g_y)) {
    x <- c(x, y)
  }}


# Tampilkan beberapa hasil Acceptance-Rejection
head(x)

# Cek jumlah amatan
length(x)
[1] 100

3. Direct Transformation

Direct Transformation Method adalah teknik pembangkitan bilangan acak dengan cara mentransformasikan satu atau beberapa peubah acak yang mudah dibangkitkan menggunakan rumus tertentu, sehingga diperoleh peubah acak dengan distribusi yang diinginkan.

Hubungan dan Transformasi Antar Distribusi Peluang

Contoh:

Bangkitkan 1000 peubah acak \(Y\sim N(0,1)\). Dengan menggunakan Direct Transformation \(X=Y^2\), bangkitkan peubah acak \(X\sim\chi^2(1)\), kemudian bandingkan histogram hasil transformasi dengan PDF teoritis distribusi Chi-square.

# membangkitkan 1000 bilangan acak dari distribusi Normal standar
y <- rnorm(1000)

# mentransformasikan setiap nilai Y dengan cara dikuadratkan.
x <- y^2

# membuat histogram hasil transformasi X
hist(x, prob=T, col="lightgreen")

# membuat deret nilai dari 0 sampai 13 dengan selang 0,01
sbx <- seq(0,13,0.01)

# menambahkan kurva PDF teoritis distribusi Chi-square dengan derajat bebas 1 pada histogram
lines(sbx, dchisq(sbx,df=1), col="red")
